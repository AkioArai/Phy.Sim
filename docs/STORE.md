# Магазины приложений

Приложение уже распространяется без магазинов: APK из выпусков на GitHub, сайт
с установкой «на главный экран», одиночный HTML. Этот файл — для того, кто
решит выложить его ещё и в каталог. Тексты описаний лежат в
`fastlane/metadata/android/` (ru-RU и en-US) — в формате, который читают
F-Droid и инструменты Google Play.

| Что | Где | Предел |
|---|---|---|
| название | `title.txt` | 50 символов |
| короткое описание | `short_description.txt` | 80 символов |
| полное описание | `full_description.txt` | 4000 символов |
| что нового | `changelogs/<versionCode>.txt` | 500 символов |

`versionCode` считается из версии: `MAJOR·10000 + MINOR·100 + PATCH`
(`packaging/android/build-apk.mjs`), для 3.0.0 это `30000`.

Снимки экрана лежат в `docs/media/` (`05-mobile.png`, `06-mobile-tools.png` —
телефон; `01…04` — планшет и компьютер). Для F-Droid их копируют в
`fastlane/metadata/android/ru-RU/images/phoneScreenshots/` при подаче; в
репозитории их второй раз не держим, чтобы не раздувать историю.

## F-Droid

Подходит лучше всего: код открыт (GPL-3.0), сборка без закрытых библиотек, ноль
разрешений, ни одного сетевого запроса.

1. Форк `fdroiddata`, файл `metadata/ru.physim.app.yml`: лицензия `GPL-3.0-only`,
   категория `Science & Education`, `SourceCode` и `IssueTracker` — ссылки на
   репозиторий, сборка — `node packaging/android/build-apk.mjs` на теге выпуска.
2. F-Droid подписывает APK своим ключом. Поставить его поверх нашего APK нельзя —
   это нормально, скажите об этом в описании.
3. Описания и «что нового» F-Droid возьмёт из `fastlane/` сам.

## RuStore

Нужен аккаунт разработчика (физическое лицо или самозанятый). Загружается тот же
подписанный APK из выпуска. Возрастная категория — 0+, реклама — нет, данные
пользователей — не собираются. Тексты — из `ru-RU`.

## Google Play

Нужен аккаунт разработчика (разовый взнос) и формат AAB вместо APK: текущая
сборка его не делает — это отдельная работа (`bundletool`). В анкете «Безопасность
данных»: данные не собираются и не передаются. Целевая аудитория — 13+, так как
пособие рассчитано на школьников старших классов и студентов.

## Чего не делать

- Ключ подписи (`*.keystore`) в репозиторий не кладётся никогда — он в секретах CI.
- Никаких разрешений: пособию не нужны ни сеть, ни память, ни камера. Если
  магазин просит «обоснование разрешения», значит, в сборку что-то попало лишнее.
- Почта автора в метаданных пакета — служебная `@users.noreply.github.com`.
